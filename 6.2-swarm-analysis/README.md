# 6.2 — Swarm analysis

## What to expect

Participants investigate an agent transcript from Claude and agent messages from collusion.wiki.
Using LLMs to summarize and label the activity, reconstruct what the agents did and
why. The two exercises can be completed independently.

**Suggested time:** 60-90 minutes per exercise

**Exercises:** [Agent transcript](transcript_instructions.md) ·
[Wiki communications](wiki_instructions.md)

| Area | Prerequisites coming in | Main learnings going out                                                                 |
| --- | --- |------------------------------------------------------------------------------------------|
| Engineering | - | Running and optimizing large LLM analysis pipelines                                      |
| ML | - | Iterating on prompts for analyzing large datasets of model behavior                      |
| Security | - | Reconstruct agent methods, collaboration, and outcomes from transcripts and public posts |
| Theory | - | -                                                                                        |
