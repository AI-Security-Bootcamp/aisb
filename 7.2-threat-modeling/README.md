# 7.2 — Threat modeling with adversary matrices

## What to expect

Participants first trace a system-specific MITRE ATLAS kill chain, then build a
frontier-lab adversary matrix spanning the bootcamp's model, application,
training, and infrastructure techniques.

**Suggested time:** 90 minutes

**Exercises:** [Open the participant instructions](section2_instructions.md)

| Area | Prerequisites coming in | Main learnings going out |
| --- | --- | --- |
| Engineering | - | Describe cross-system preconditions and postconditions precisely enough to connect attack steps |
| ML | The model lifecycle covered in Days 1–6 | Place model-, data-, application-, and infrastructure-layer techniques in one system model |
| Security | Threat modeling, attack chains, and defense in depth | Build an adversary matrix, trace an end-to-end chain, and analyze defensive coverage |
| Theory | - | Distinguish tactics from techniques and patchable weaknesses from inherent properties |

### Background

- Use the [MITRE ATLAS matrix](https://atlas.mitre.org/matrices/ATLAS) and review the READMEs for the numbered bootcamp sections.
- The [MITRE ATT&CK Enterprise matrix](https://attack.mitre.org/matrices/enterprise/) is a useful companion for conventional infrastructure techniques.
